# Audit 2026-11-12 — semua halaman, komponen, dan app

Lanjutan dari `docs/AUDIT-2026-11-11.md`. Audit ini menyisir seluruh route publik
(EN + ID), dev routes, dashboard, dan auth pada 7 lebar viewport, lalu memperbaiki
bug yang ditemukan. Referensi kualitas visual: `FLUID STUDIO` (analisis via DOM +
computed style, bukan gambar).

## Lingkup & metode

- Route publik EN/ID: `/`, `/about`, `/media-kit`, `/products`,
  `/products/dualbrand`, `/work`, `/work/sakolentra`, `/services`, `/journal`,
  `/faq`, `/start`, `/privacy`, `/terms`, `/license`, `/links`, `/cv`.
- Dev: `/dev/components`, `/dev/wiring`. App: `/dashboard/*`, `/sign-in`.
- Viewport: 320, 375, 390, 768, 1024, 1280, 1440.
- Pemeriksaan: status HTTP, overflow horizontal, duplicate `id`, urutan heading,
  label input, tap target, console/page error, canonical, `hreflang`, OG/Twitter,
  `robots`, dan axe (WCAG 2.x AA, light + dark).
- Server lokal di port 3100. Produksi tidak disentuh.

## Bug yang diperbaiki

1. **Nav floating tidak bisa diklik (kritis).** `view-transition-name` pada
   `<header>` membentuk stacking context di bawah `<main>`, sehingga pill nav
   tampil tetapi klik jatuh ke hero. Perbaikan: `relative z-[var(--z-nav)]` pada
   `<header>`. Regresi dijaga oleh test Playwright baru.
   - `src/components/site/header.tsx`
   - `tests/wiring/landing.spec.ts`
2. **Overflow 320px** pada `/about`, `/media-kit`, `/id/products/dualbrand`
   (harga dan tombol CTA `shrink-0` + label lisensi panjang). Perbaikan:
   `w-full sm:w-auto`, `whitespace-normal`, dan hapus `shrink-0` pada kontainer
   harga/CTA.
3. **Tap target < 24px** pada "Browse all products", catatan "pending
   confirmation" di `/links`, dan link nav dev. Perbaikan: `min-h-7` +
   `inline-flex items-center`.
4. **`/dev/components` 404.** Route memakai data dinamis; layout dev diberi
   `export const dynamic = "force-dynamic"`.
5. **React #418 di `/dev/wiring`.** Theme/locale dibaca saat render. Diganti
   `useSyncExternalStore` (mounted flag) agar HTML server dan klien sama.
6. **Metadata SEO hilang per halaman.** Semua halaman memakai title default.
   Ditambah helper `src/lib/seo.ts` (`pageMetadata`) dengan title, description,
   canonical, `hreflang` EN/ID, OG image 1280×720, dan Twitter card. Diterapkan
   ke seluruh route publik dan `/work/[slug]`.
7. **Dashboard & auth bisa terindeks.** Ditambah `robots: noindex, nofollow`
   pada layout dashboard dan layout `(auth)` baru.
8. **`/dashboard` tanpa sesi membocorkan error DB di dev.** Di produksi sudah
   redirect ke `/sign-in`; test sekarang memverifikasi redirect 307 ke route
   sign-in yang benar (bukan `/auth/`).

## Catatan non-issue

- `Skip to content` 1×1 px, superscript `¹²³`, dan link inline dalam paragraf
  adalah pengecualian yang sah.
- Gambar Next.js `fill` memang tidak punya `width`/`height`; bukan bug CLS.
- `color-contrast` pada wordmark dekoratif `aria-hidden` dan `.text-foreground/20`
  diabaikan karena elemen dekoratif.
- Overlay intro studio memblokir klik ~1,3 detik; perilaku modal yang disengaja.

## Butuh keputusan Owner

1. **`NEXT_PUBLIC_SITE_URL` di produksi.** Tanpa nilai ini canonical, robots,
   sitemap, dan OG memakai `http://localhost:3000`.
2. **`OUTBOUND_LINKS` belum diverifikasi.** `dualbrand` dan `dualbrand-demo`
   masih `verified: false`; `/go/dualbrand-demo` menuju domain yang DNS-nya
   belum resolve. Putuskan: verifikasi URL atau sembunyikan CTA.
3. **DNS `dualbrand.andypratama.studio`** tidak resolve.
4. **`pnpm db:up`** tercantum di `AGENTS.md` tetapi tidak ada di `package.json`
   dan folder `docker/` tidak ada.
5. **Dashboard query DB sebelum guard auth** (fallback + `ER_ACCESS_DENIED` di
   log saat MySQL mati). Pindahkan guard ke level data atau pastikan DB siap.
6. **Newsletter mati secara default** (`NEWSLETTER_ENABLED=0`).
7. **Secret fallback produksi** (`BETTER_AUTH_SECRET`, `AGENT_SECRET_KEY`).
8. **Identitas owner** masih beda antara kode/`.env.example` dan identitas
   GitHub yang diminta; belum diubah.
