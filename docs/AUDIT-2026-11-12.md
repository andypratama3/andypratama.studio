## Batch 1 — audit tampilan (12 Nov)

1. **Nav floating tidak bisa diklik (kritis).** `view-transition-name` pada
   `<header>` membentuk stacking context di bawah `<main>`, sehingga pill nav
   tampil tetapi klik jatuh ke hero. Perbaikan: `relative z-[var(--z-nav)]`.
   Regresi dijaga test Playwright.
2. **Overflow 320px** pada `/about`, `/media-kit`, `/id/products/dualbrand`
   (harga & tombol CTA `shrink-0`). Perbaikan: `w-full sm:w-auto`,
   `whitespace-normal`, hapus `shrink-0`.
3. **Tap target < 24px** pada "Browse all products", catatan "pending
   confirmation", dan link nav dev.
4. **`/dev/components` 404** — layout dev diberi `dynamic = "force-dynamic"`.
5. **React #418 di `/dev/wiring`** — diganti `useSyncExternalStore` (mounted flag).
6. **Metadata per halaman** — helper `src/lib/page-metadata.ts` (canonical,
   hreflang en/id/x-default, OG image, Twitter card) dipakai 17 halaman.

## Batch 2 — integrasi `origin/main` + audit app (14 Nov)

`origin/main` (7 commit: DB, auth owner, dashboard tulis, copy deck, compose,
Dockerfile) di-merge ke `rebuild/studio`; konfirmasi di-resolusi dengan
mempertahankan fix Batch 1 dan memakai helper metadata milik `main`.

Bug baru yang ditemukan dan diperbaiki:

1. **Build produksi gagal tanpa `DATABASE_URL`.** `src/db/index.ts` melempar
   error saat di-import, sehingga `next build` (collect page data) dan CI
   gagal. Perbaikan: pool + drizzle dibuat lazy lewat proxy; error hanya
   muncul saat query benar-benar dijalankan. Regresi: `tests/db-lazy.test.ts`.
2. **Build produksi gagal tanpa `BETTER_AUTH_SECRET`/`OWNER_EMAIL`.**
   `src/lib/auth.ts` melempar saat import → prerender `/sign-in` gagal.
   Perbaikan: validasi dipindah ke waktu pakai (`isAuthConfigured()`);
   `getOwnerSession()` mengembalikan `null` (fail-closed), `requireOwner()`
   melempar, `/api/auth/*` membalas 503 dengan pesan jelas.
3. **E2E `/go/threads-start` gagal tanpa MySQL.** Short-link sosial hanya ada
   di tabel `links`. Perbaikan: slug yang sama (sudah tercantum di
   `src/db/seed.ts`) ditambahkan sebagai fallback statis terverifikasi di
   `src/content/outbound-links.ts`; baris DB tetap menang.
4. **`DASHBOARD_DEV_BYPASS` tidak pernah aktif.** Proxy selalu redirect
   `/dashboard` bila tidak ada cookie sesi, sehingga bypass yang didokumentasikan
   di `.env.example` tidak bisa dipakai. Perbaikan: proxy menghormati bypass
   di luar produksi.
5. **Halaman `/dev/*` bisa terindeks.** Layout dev kini `noindex, nofollow`
   (regresi: test wiring "diagnostic routes stay out of the index").
6. **Form kontak menyembunyikan pesan API.** Galat non-2xx selalu diganti
   teks generik. Perbaikan: pesan API ditampilkan (mis. "email
   contact@andypratama.studio"), fallback teks tetap memakai email tersebut.
7. **CSRF origin check terlalu ketat.** Hanya `NEXT_PUBLIC_SITE_URL` yang
   diterima, sehingga preview/lokal membalas 403. Perbaikan: canonical origin,
   origin request, dan origin yang cocok dengan host request sama-sama
   diterima; origin lintas situs tetap ditolak (regresi:
   `tests/request-security.test.ts`).
8. **Redirect newsletter tidak mengikuti bahasa.** Pelanggan ID diarahkan ke
   `/newsletter` (EN). Perbaikan: `confirm`/`unsubscribe` memakai locale
   pelanggan → `/id/newsletter`.
9. **Metadata duplikat.** Helper `src/lib/seo.ts` saya dan
   `src/lib/page-metadata.ts` milik `main` berdampingan. Perbaikan: satu
   helper (`page-metadata.ts`) + OG image untuk semua halaman; `seo.ts`
   dihapus.
10. **Link "Kembali ke beranda" di `/newsletter`** hanya 17px tinggi →
    `inline-flex min-h-7 items-center`.
11. **Baseline e2e menulis ke dokumen ter-tracking.** Spec motion menulis ke
    `docs/baseline/before` (ikut berubah tiap `pnpm test:e2e`). `main` sudah
    memindahkannya ke `test-results/baseline` dan meng-ignore `test-results/`.
