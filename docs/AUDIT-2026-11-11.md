## Perbaikan yang diterapkan

1. **Border ganda baris layanan** — `Row` tidak lagi memakai `first:border-t`;
   container Home dan baris Work yang memberi `border-t`. Tes regresi ditambahkan.
2. **`/links` menggantung** — `/go/*` memakai `Link` next-intl sehingga RSC
   prefetch ke URL eksternal diblokir CSP. Diganti anchor biasa (plus di
   `products/dualbrand`). Tidak ada lagi error CSP / request `_rsc` ke `/go/`.
3. **Redirect dashboard 404** — layout mengarah ke `/auth/sign-in` yang tidak ada.
   Sekarang `redirect({ href: "/sign-in", locale })`; hasil `307 -> /sign-in`.
4. **Kontras hover di surface gelap** — `text-brand` (#433bff, 3.21:1) diganti
   `brand-on-dark` (#6f69ff, 4.99:1) pada brand nav dan path card.
5. **Tap target brand** — 44px (`inline-flex min-h-11`), tanpa truncation.
6. **Sign-out / sign-in** — memakai router i18n, bukan path hardcoded.
7. **CI e2e rusak** — job e2e tidak punya `.next` dan menyalakan server sendiri
   sementara `webServer.reuseExistingServer=false` (Playwright menolak port terpakai).
   Ditambahkan langkah build; server dikelola Playwright.
8. **Indexing sign-in/dashboard** — `robots.txt` + `X-Robots-Tag: noindex` untuk
   `/sign-in`, `/id/sign-in`, `/dashboard`, `/{en,id}/dashboard/*`.
9. **`.env.example` tidak lengkap** — ditambah `OWNER_EMAIL`, `AGENT_SECRET_KEY`,
   `NEXT_PUBLIC_APP_URL`, `ENABLE_DEV_ROUTES`.
10. **Auth client** — fallback `NEXT_PUBLIC_APP_URL → NEXT_PUBLIC_SITE_URL →
    localhost` agar produksi tidak memanggil `localhost:3000`.
11. **Hover kartu jurnal Home** — `group-hover` tanpa `group`; kelas `group` ditambah.
12. **Inventory plugin basi** — drizzle & better-auth tidak lagi "missing"
    (schema/migration/auth sudah ada), status menjadi "partial" dengan catatan env.

## Temuan yang butuh keputusan Owner

1. **Identitas owner tidak konsisten.** Kode + `.env.example` memakai
   `andypratamaworkspace@gmail.com`; identitas GitHub yang diminta adalah
   `andypratama1211@gmail.com`. Jangan diubah tanpa konfirmasi.
2. **Secret fallback produksi.** `BETTER_AUTH_SECRET` dan `AGENT_SECRET_KEY`
   punya nilai default yang diketahui publik bila env kosong. Sebaiknya
   fail-closed di produksi, tetapi perubahan ini bisa memblokir deploy yang
   belum mengisi env.
3. **Link outbound belum terverifikasi.** `OUTBOUND_LINKS.dualbrand*.verified=false`
   namun `/links` tetap menampilkan tautan yang bisa diklik. Kebijakan
   publish/gating perlu diputuskan.
4. **Aset belum ada.** Video intro hanya poster + teks "Video coming soon";
   Unicorn Studio masih fallback statis (`NEXT_PUBLIC_UNICORN_PROJECT_ID` kosong).
5. **Newsletter mati secara default** (`NEWSLETTER_ENABLED=0`); API menolak
   dengan 503/404. Aktifkan hanya setelah transport mail siap.
6. **Hero mobile** ~1039px pada 375×667 (bukan tepat `100svh`); CTA utama dan
   sekunder terlihat, kartu jalur mulai ~649px. Perlu keputusan desain bila
   ingin hero benar-benar satu layar.
7. **Metadata per halaman belum ada.** Semua halaman memakai title default
   "Andy Pratama Studio". Perlu judul/deskripsi per halaman untuk SEO.
8. **Dashboard query DB sebelum guard auth.** Saat MySQL tidak ada, log
   `ER_ACCESS_DENIED` muncul dan halaman memakai fallback. Pindahkan guard ke
   level data atau pastikan DB selalu tersedia.
9. **`pnpm db:up` tidak ada** di `package.json` walau tercantum di `AGENTS.md`;
   folder `docker/` juga tidak ada. Pilih: tambah compose atau perbaiki dokumen.
10. **`NEXT_PUBLIC_SITE_URL` wajib di produksi.** Tanpa itu `robots.txt`,
    `sitemap.xml`, dan `isAllowedBrowserOrigin` memakai `localhost:3000`.
